# ChooseMemeGame в браузере
На хосте с Docker Compose выполните:
```sh
docker compose build server
docker compose up -d --pull never
```
Откройте http://localhost:8091 на хосте или http://IP-Мака:8091 из общей локальной сети. На Mac адрес Wi-Fi обычно показывает `ipconfig getifaddr en0`. У каждого из четырёх мест свой порт (8091–8094) и отдельный JavaFX-клиент. Выберите разные места, введите ники, создайте лобби и присоединитесь к нему. Игроки подключаются без пароля, поэтому используйте доверенную локальную сеть.

Сервер на порту 4555 работает внутри Compose. Партии хранятся в памяти. Закрытие вкладки оставляет игровой клиент на месте, повторное открытие того же места возвращает его экран. Для остановки используйте `docker compose stop`, для запуска — `docker compose start`. Состояние и журнал — `docker compose ps` и `docker compose logs --tail 50`.

В исходниках отсутствуют PNG. Сборка добавляет резервные изображения интерфейса и колоду реакций. Свои изображения можно положить в каталог ресурсов игры до сборки.
